Hello, this is going to be my first solo project, i will be attempting to make Conways game of life using tKinter and python!
-the width and height, (num of cells) must be picked when starting using system arguments: "Usage: python3 main.py <width> <height>"
-constants contains variables that can change cell colour, size and the speed of simulation.
-button inputs can be blocked or unblocked in def game_loop in main.py
-You can start the game by pressing space :)
